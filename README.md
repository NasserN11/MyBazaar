# MyBazaar - E-Commerce Console Application

## Project Overview

MyBazaar is a Java-based console application that simulates a simple e-commerce platform. Users can register as buyers or sellers, list items, manage shopping carts, place orders, and create product campaigns. The project follows object-oriented design principles and UML-based implementation as outlined in the SENG271 project specification.


## Core Features

- User registration and login (Buyer / Seller roles)
- Sellers can add, update, and remove items
- Buyers can browse items, add to cart, and place orders
- Shopping cart management (add/remove items, view total)
- Campaign creation (percentage or amount discounts) based on product categories
- Order history and total spending tracking
- Persistent in-memory storage (no external database required)
